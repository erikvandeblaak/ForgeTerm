# Security policy

ForgeTerm runs shells and AI coding agents, so security reports are taken seriously.

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately through GitHub:
[Report a vulnerability](https://github.com/erikvandeblaak/ForgeTerm/security/advisories/new),
or by e-mail to erik@vandeblaak.com.

Include the version, platform, the steps to reproduce and what an attacker could do. You will get an answer within a week.

Examples of what counts: terminal output or a repository that makes ForgeTerm run a command, send input to a shell or agent, open a non-http(s) link, write files, or start a program configured by the repository.
